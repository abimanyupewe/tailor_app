# Visual audit

Scope: global Flutter theme and auth-aligned green palette.

Homepage pass: the header now carries the auth green, search and service shortcuts use the same token family, and tailor lists expose a clear empty state.

Category/search pass: category tiles now have a roomier three-column layout, while category and search headers share the auth green and search empty state uses the sage surface.

## Findings

1. LOW — Service shortcuts previously used orange, blue, purple, pink, and green independently. They now use the existing forest-green and sage tokens so the home surface follows the auth palette (R-29).

2. LOW — Semantic colors remain in order status, errors, warnings, and ratings. These are intentionally retained because they communicate state rather than branding (R-01, R-29).

## Result

The global theme now uses `AppColors.primary` (`#173834`) for primary controls, focused fields, progress indicators, selection controls, text buttons, outline buttons, navigation, and auth screens. No high-priority visual findings remain in the edited scope.
